Residual kidney function

Interdialytic collection interval
After previous dialysis → before the selected BUN collection session
—
Calendar gap minus the duration of the previous dialysis session. Assumes collection begins after that HD ends and ends just before the next HD starts; no intervening dialysis.

The model uses a time-weighted average SUN for the modeled collection period, not a fixed percentage of one pre-HD BUN. Confirm actual start and end times match this assumption.
